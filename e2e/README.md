# Сквозные тесты

Сценарии в настоящем браузере (Chromium через Playwright): каждый тест создаёт своих пользователей
и мероприятия через API, поэтому их можно запускать на любой базе, в том числе с демо-данными.

| Тест | Что проверяет |
| --- | --- |
| `01-auth` | регистрация, вход, ошибки по полям, выход, протухший токен, телефон |
| `02-home-demo` | демо-табель на главной: мышь, протягивание, клавиатура, касание |
| `03-themes` | палитры: выбор гостя попадает в профиль, переезжает в другой браузер |
| `04-events` | создание, ссылка-приглашение, гость регистрируется по ссылке и присоединяется |
| `05-availability` | своя сетка: протягивание, ручки, крестик, Delete, «Очистить», сбой сети, телефон |
| `06-heatmap` | тепловая карта, подсказка с именами, время одного участника, подсказка команды |
| `07-best-slot` | лучшее время, обязательные участники, «если очень надо», назначение |
| `08-live-tz-guest` | живые обновления, часовые пояса, гость по имени, `.ics`, правка и удаление |

## Запуск

Нужны запущенные клиент (`:5173`) и сервер (`:3000`) — `docker compose up` или `npm run dev` в обоих.

```bash
cd e2e
npm install
npx playwright install chromium
npm test
```

Другие адреса: `E2E_BASE=http://localhost:8080 E2E_API=http://localhost:8080/api npm test`.
Скриншоты сохраняются в `e2e/screenshots/`.
