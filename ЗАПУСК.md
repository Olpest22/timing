# Как запустить проект «Тайминг»

Ничего, кроме Docker Desktop, ставить не нужно: база данных, сервер и сайт запускаются сами.

## 1. Установить Docker Desktop (один раз)

1. Скачать с https://www.docker.com/products/docker-desktop/ и установить.
2. Если установщик попросит включить WSL 2 — согласиться и перезагрузить компьютер.
3. Запустить Docker Desktop и дождаться, пока внизу слева появится «Engine running».

## 2. Открыть проект

1. Распаковать папку `timing` (если пришла архивом).
2. В VS Code: **File → Open Folder** → выбрать папку `timing`.
3. Открыть терминал: **Terminal → New Terminal** (или `Ctrl` + `` ` ``).

## 3. Запустить

В терминале:

```
docker compose up --build
```

Первый запуск занимает 3–5 минут. Готово, когда в логах появится `API listening on http://localhost:3000` и `Local: http://localhost:5173/`.
Этот терминал не закрывать.

## 4. Добавить демо-данные (один раз)

Открыть второй терминал (кнопка **+** в панели терминала) и выполнить:

```
docker compose exec server npm run db:seed:prod
```

## 5. Открыть в браузере

- Приложение: http://localhost:5173
- Вход: `anya@demo.timing`, пароль `demo123`
- Документация API: http://localhost:3000/api/docs

## Остановить

В первом терминале нажать `Ctrl` + `C`. В следующий раз достаточно `docker compose up` (шаг 4 не нужен — данные сохраняются).

## Если не запускается

| Сообщение | Что сделать |
| --- | --- |
| `error during connect … dockerDesktopLinuxEngine` | Не запущен Docker Desktop — запустить и подождать «Engine running» |
| `no configuration file provided` | Терминал открыт не в папке `timing` — открыть в VS Code именно её |
| `port is already allocated` (5432, 3000 или 5173) | Порт занят другой программой (например, установленным PostgreSQL) — закрыть её |
